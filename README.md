# data — 기계가 쓰는 상태

이 브랜치는 파이프라인이 쓴다. 사람이 고칠 일은 없다. 코드는 `main`에 있다.

| 경로 | 내용 |
|---|---|
| `live/` | 수집 체크포인트: 소스별 마지막 정상 관측과 그 원문 |
| `chart-history/` | 화면 표시용 원빈도 이력과 원문 |
| `history/` | 모델 입력 계열의 전체 이력과 개정 기록 |
| `public/` | 사이트에 게시되는 `live-data.json`·`chart-data.json` |

- `known_by`는 실제 수집시각이다. 최초 발표시각이나 과거 빈티지를 인증하지 않는다.
- 재배포가 금지된 가격 계열의 값은 여기에 저장하지 않는다.
- 첫 커밋은 이전 저장소 macro-liquidity-dashboard 의 상태(커밋 6be774a)를 그대로 이어받은 것이다. 최초 수집시각을 보존하기 위해서다.
